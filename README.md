# 能量日历 · Energy Calendar

一张按春夏秋冬配色的全年日历：每天一个能量块，外加一条事件备注。

![season](https://img.shields.io/badge/season-%E5%86%AC%E8%93%9D%C2%B7%E6%98%A5%E7%BB%BF%C2%B7%E5%A4%8F%E7%BA%A2%E9%BB%84%C2%B7%E7%A7%8B%E9%9D%92%E8%93%9D-4a6fd0)

## 用法

直接用浏览器打开 `index.html`，或访问 GitHub Pages 在线版。单文件、零依赖、无需构建。

## 功能

- **12 个月平铺**，每月一张卡片（7 列 × 6 周），一张图看完一整年
- **季节配色**：冬 = 靛蓝紫 / 春 = 绿 / 夏 = 红黄 / 秋 = 青蓝；季内小幅渐变，季间大幅跳色，月份标题带季节徽章
- **能量块**：每格明暗对应 0–5 级，颜色取自当月的色相
- **缩放**：滚轮缩放 6–46px，列数自动在 6 / 4 / 3 / 2 之间切换，最小正好是「12 个月铺满一屏」
- **事件标记**：点击格子 → 记录能量 + 写一条备注 + 选一个 emoji；有事件的格子右上角显示 emoji 角标，鼠标悬浮查看完整内容
- **今日与本周**：今天用白青渐变高亮，本周剩余日期青色渐隐
- **数据**：localStorage 自动保存，支持导入 / 导出 JSON

## 快捷操作

| 操作 | 说明 |
| --- | --- |
| 滚轮 | 缩放（Shift 加速） |
| 点击格子 | 打开编辑弹层 |
| ← → | 切换年份 |
| + / − | 缩放 |
| 0 | 回到铺满视图 |
| Enter / Esc | 关闭弹层 |

## 数据格式

```json
{
  "year": 2026,
  "data": { "2026-11-03": 4 },
  "notes": { "2026-11-15": { "t": "季度复盘会", "e": "🎯" } }
}
```

`data` 是每日能量（0–5），`notes` 是事件备注（`t` 文字、`e` emoji）。导入时也兼容 `{"2026-11-03": 4}` 这样的纯能量映射，以及 `notes` 里直接写字符串。

## 说明

打开时默认显示**演示数据**（固定种子生成，仅用于展示形态，不写进导出文件）。点击左上角「演示数据」可切换为空白，从头记录自己的数据。
